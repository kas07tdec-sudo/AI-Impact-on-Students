# 📊 Impact of AI on Students — Data Analytics & ML Project

An empirical data analytics and machine learning project evaluating the impact, adoption rates, academic integrity correlations, and productivity shifts associated with Artificial Intelligence tools among modern learners.

---

## 🌟 Key Features & Insights

* **🧹 Automated Data Preprocessing:** Cleaned and standardized raw demographic and survey telemetry using Pandas and NumPy data pipelines.
* **🤖 Predictive Modeling:** Applied Scikit-Learn algorithms (classification and regression) to model relationships between AI tool usage frequency and academic performance metrics.
* **📈 Dynamic Power BI Dashboards:** Built interactive multi-page dashboards featuring real-time filters, demographic slicers, and KPI visual cards.
* **📊 Exploratory Data Analysis (EDA):** Quantified key adoption trends across different study disciplines and educational levels.

---

## 🛠️ Tech Stack & Tools

* **Language:** Python 3.x
* **Data Processing:** Pandas, NumPy
* **Machine Learning & Statistics:** Scikit-Learn, SciPy
* **Data Visualization:** Power BI, Matplotlib, Seaborn
* **Environment:** Jupyter Notebook / VS Code
